## Overview

Phrasebox records a melodic phrase and intelligently transposes it into the scale of any chord played, preserving the melodic contour while adapting harmony, for chord-following lead lines and basslines.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Venomode Phrasebox** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Phrase Recorder** | Record up to 32-step melodic phrases from a MIDI keyboard |
| **Chord Transposition** | Phrase intervals snap to the played chord and scale context |
| **Quantize Grid** | Align recorded notes to 1/16th, 1/8th, or triplet grids |
| **Playback Modes** | Forward, backward, random, and ping-pong phrase playback |
